# THE-CALM-CHAOS - Multilingual AI Chatbot

## 🌍 Idea
A multilingual AI chatbot that understands and responds in multiple languages using Google's Gemini API.

## 🎯 Problem
Many non-English speakers struggle to use AI tools. Language shouldn't be a barrier to accessing AI.

## ✅ Solution
Built a chatbot that:
- Works in multiple languages (English, Tamil, Hindi, Spanish, etc.)
- Understands user input in any language
- Responds intelligently in the same language
- Stores chat history for each user

## 🛠️ Tech Stack

| Component | Technology |
|-----------|------------|
| Authentication | Firebase Authentication |
| Database | Firestore (NoSQL) |
| AI Engine | Gemini API |
| Backend | Cloud Run |
| Frontend | HTML/JavaScript |

## 🚀 Features
- Multi-turn conversations in any language
- User authentication via Firebase
- Persistent chat history in Firestore
- Real-time language detection
- Secure API key management with Google Cloud Secret Manager

## 📱 Supported Languages
- English
- Tamil
- Hindi
- Spanish
- (More can be added)

## 🔧 How It Works
1. User logs in with Firebase
2. Selects preferred language
3. Types message in their language
4. Gemini API processes and understands
5. AI responds in the same language
6. Chat history saved in Firestore

## 💡 Why This Matters
India has 22 official languages. This project makes AI accessible to millions of non-English speakers, breaking the language barrier.
